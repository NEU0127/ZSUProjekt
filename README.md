# Základy strojového učení – Semestrální projekt

Tento repozitář vznikl k řešení semestrálního projektu předmětu Základy strojového učení

## 📂 Struktura projektu

Projekt je rozdělen na dvě části.
1. **Část 1: Exploratorní a shluková analýza**
1. **Část 2: Klasifikace**

## 📊 Použitá data

Projekt využívá dva různé datasety, pro každou část projektu jiný

1. **Část 1: Olympijští sportovci (https://www.kaggle.com/datasets/heesoo37/120-years-of-olympic-history-athletes-and-results)**
   * **Obsah:** Fyzické a demografické atributy sportovců z historie OH.

2. **Část 2: Zpoždění německých vlaků (https://www.kaggle.com/datasets/nokkyu/deutsche-bahn-db-delays)**
   * **obsah:** Logistická a časová data vlakových spojení.
